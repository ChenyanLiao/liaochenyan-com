01

从结构准备到多轮筛选与分析

MolloM 将结构准备、多轮对接、分子动力学与分析连接起来。你可以在本机或授权的 SSH 服务器上使用已适配的软件，在项目中核对参数、追踪任务，并查看结果与日志。

  1. 01

    连接环境，检查输入

    选择本机或授权的 SSH 服务器。软件中心可检测或登记已有程序，为部分适配工具提供安装、版本管理和验证入口；实际可用性取决于系统、许可和计算节点。导入受体与配体后，在三维视图中检查结构并设置对接盒子。

  2. 02

    选择引擎，核对参数

    按所选引擎配置搜索强度、随机种子和 CPU／GPU 资源，先用小批次试跑估算计算时间，再确认并提交。不同引擎的适配程度不同；排队和数据传输时间需另行考虑。

  3. 03

    筛选、继续与分析

    查看任务进度、日志和 pose，按分数及其他可用指标筛选候选；保留来源建立下一轮，自由选择引擎与参数。支持的导出可检查冲突并在中断后明确续做；选定 pose 还可交接至 GROMACS，或独立查看已有轨迹与分析结果。

02

桌面端与移动端

桌面端

连接本机或自己的 SSH 服务器，检查受体与配体、设置三维对接盒子，并选择引擎、参数和资源。按需试跑估时，查看进度与日志；通过阈值筛选候选并建立下一轮，也可交接到 GROMACS，查看轨迹与分析结果。每轮使用的引擎和参数由研究者决定。

移动端

移动端正在开发中，目标是在明确授权后查看计算端的任务进展、结果摘要与日志，保留带读取时间的离线副本，并为支持的桌面项目提供计划草稿和差异核对。远程提交需要独立授权与用户确认；具体能力以实际版本和验收结果为准。

当前开发版真实界面，使用演示配置与模拟任务；未提交真实计算。

移动端仍在开发：局域网配对和部分监控已有验证，公网、蜂窝网络与系统推送尚待验收；访问需要单独授权。本地免费功能无需云账号。官网下载为 0.307.0 桌面开发者预览，安装包的可用功能和测试范围以版本说明为准。

03

调用的软件与留下的记录

MolloM 不是新的对接或 MD 引擎，而是通过图形界面调用已有工具，并记录输入、参数、结果与任务来源。Vina、GNINA、GROMACS 和 Multiwfn 等的可用功能取决于各自适配、系统、计算节点与许可证；发现程序不等于计算节点已验证。桌面端还提供 AI 助手和 MCP 接口入口，真实模型服务及各工具的具体环境需分别验证。

04

计算位置与数据传输

对接与模拟在本机或自己指定的服务器运行。账号连接可将所选任务的状态、结果摘要与日志转发到手机；软件安装和自行启用的外部服务也会使用网络。

怎样看待计算结果

对接分数和轨迹用于比较候选，不能单独确认结合或机制。解读结果时仍需考虑分子身份、质子化、力场、采样和实验依据。

Windows 安装与使用
  1. 安装前备份已有项目，运行安装包后，在应用内核对版本为 0.307.0。
  2. 在“计算环境”添加自己的 SSH 服务器，核对主机身份、登录凭据和计算目录。不要把密码或私钥发送到反馈信息中。
  3. Windows 包不内置 Vina；远程计算端需已有对应引擎与结构准备环境。先完成软件检测，再导入受体和配体。
  4. 核对三维 box、参数和资源后明确提交。每轮按实际结果筛选并导出候选，再由你选择下一轮的引擎与参数。
